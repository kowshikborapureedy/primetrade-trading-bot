# PrimeTrade.ai — Simplified Futures Trading Bot Engine
# Project Overview
This project is a modular, high-performance command-line utility built in Python to execute and log automated derivatives transactions. The application interfaces directly with the Binance Futures Demo Platform (USDT-M) via secure API endpoints. It includes a robust client-side validation layer to filter inputs before execution, an isolated connection management framework, and structured, non-intrusive logging capabilities designed to satisfy rigorous professional code reviews.

# Core Capabilities & Features
Dual Execution Routines: Supports instantaneous MARKET order routing as well as price-targeted LIMIT order book placement. 
 Bi-Directional Order Sides: Full compliance with contract positioning, supporting both BUY (Long) and SELL (Short) parameters. 
  Strict Client-Side Validation: Pre-filters structural input variables (symbol, side, type, asset quantity, and boundary limits) before network dispatching to minimize bad API calls and reduce layout overhead. 
   Granular Production Logging: Automatically pipeline-streams runtime metrics, incoming API connection states, unique transaction signatures, and exceptional failures directly into an un-noisy, permanent local file tracker (bot.log).  
   Decoupled Architecture: Designed with clean separation of concerns, isolating the command-line entry parsing interface from the downstream core API communication wrappers.
